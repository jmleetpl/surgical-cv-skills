# 접근법별 영상 특성과 설계 수정사항

| 접근법 | 영상 원천 | 흔한 영상 문제 | 개인정보 위험 | fingerprint·설계 수정 |
|---|---|---|---|---|
| **개복** | 천장·헤드라이트·머리착용 카메라, 핸드헬드 | 카메라 이동·흔들림, 손·머리에 의한 가림, 조명 반사, 시야가 수술 내내 바뀜, 수술 부위가 화면 일부 | **높음**: 의료진 얼굴·손·수술실, 환자 신체 일부 | 관심영역(ROI) 정의 필요, 가림 프레임 비율 측정, 프레임 품질 필터 기준 사전 지정(선별 편향 기록), 거리 지표의 픽셀 스케일 변동 매우 큼 |
| **복강경 다공** | 고정 내시경 | 연기, 반사광, 렌즈 오염, 체외 장면(삽입·제거 시) | 중간: 체외 장면, 화면 오버레이 | 체외 프레임 태깅·삭제 규칙, 연기·흐림 프레임 처리 규칙 |
| **로봇 다공(Xi 등)** | 스테레오 내시경(보통 한쪽 채널만 저장) | 로봇 UI 오버레이(기구명·아이콘), 3D 정보 손실 | 중간: UI에 환자·기관 정보 표시 가능 | 오버레이가 기구 라벨을 "누설"할 수 있음(RF14: 기구 이름이 화면에 표시)·식별정보 위험(RF18) → 마스킹 또는 명시; 키네마틱스는 임상 시스템에서 보통 추출 불가 |
| **로봇 단일공(SP)** | 단일 접근 내시경 | 기구가 화면 한쪽에서 모여 들어옴, 기구 관절 굴곡, 견인 기하 다름 | 위와 동일 | 다공 공개 데이터와 도메인 차이 큼 → 전이 실험 시 같은 아키텍처·전처리로 통제 |
| **연성 내시경(ESD·ERCP 등)** | 연성 스코프 | 근접 시야, 물·출혈, 빠른 움직임 | 낮음–중간 | 프레임 품질 기준, 시야 상실 구간 처리 |
| **현미경(신경·안과·미세)** | 수술 현미경 | 고배율, 얕은 피사계심도, 초점 이동 | 낮음 | 작은 구조(FP3.1) 기본 TRUE, 확대율 변화로 픽셀 스케일 변동 |
| **형광(ICG·자가형광)** | 동일 스코프의 모드 전환 | 같은 비디오 안의 영상 도메인 변화, 오버레이 색 | — | 모드를 메타데이터로, **모드별 층화 평가**, 형광 강도는 정량(회귀) → 범위 밖 |
| **수술 중 초음파** | 별도 프로브 영상(PIP 또는 별도 저장) | 화면 속 화면, 동기화 | — | 별도 영상 도메인으로 다루고 범위 밖(정합·3D)은 명시 |

## 공통 체크
- 녹화 해상도·fps·코덱이 기간 중 바뀌었는지(장비 교체) → 메타데이터로 기록, 하위군 분석.
- 화면 오버레이(시간, 기구명, 환자 정보)는 개인정보와 라벨 누설 양쪽 문제.
- 체외 장면·사람 노출 프레임 삭제는 **단계별로 불균등**(준비·종료 단계에 몰림) → 단계 분포 편향을 보고.
- 스테레오를 한쪽만 저장했다면 깊이 관련 과제는 범위 밖.
