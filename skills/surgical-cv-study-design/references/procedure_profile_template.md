# 수술 프로파일 작성 양식 (목록에 없는 수술용)

```markdown
## [수술명] ([접근법: 개복/복강경/로봇 다공/단일공/내시경/현미경])
작성: YYYY-MM-DD · 상태: 초안 / 연구팀 확정(확정자: )

1. 단계 온톨로지 (SAGES 계층: 수술 > phase > step > task > action; 술식 변형별 **조건부 단계** 표시)
   - phase 목록과 **시작·종료 경계 규칙**(어떤 장면에서 바뀌는가):
   - 공개 데이터셋 온톨로지와의 대응표(있으면):
2. 핵심 해부·위험구조 (구조 | 손상 시 결과 | 영상에서 보이는 단계 | **노출 전에도 보이는가**(아니면 영상 정답 없음) | 크기·형태: 작음/관형/막/영역)
3. 안전 확인지점 (CVS에 해당하는 것: 무엇이 보여야 다음 단계로 가는가, 판정 시점)
4. AI가 줄이려는 사건 (합병증·실수·지연, **정의와 중증도 기준**, 기관 내 빈도 — 희귀하면 이벤트 수가 표본수를 결정)
5. 기구 목록 (같은 종류 동시 출현 가능? → InS/ObD)
6. 영상 특성 (approach_modifiers.md 항목 + 형광/초음파/3D 여부, 해상도·fps)
7. 개인정보 위험 구간 (체외 장면, 사람, 화면 오버레이 텍스트)
8. 수술 특이 fingerprint (FP 코드별 예상값과 확인 방법)
9. 관련 공개 데이터셋 (sources.md 검증 후)
10. 술식 변이·층화 변수 (술식 유형, 변이 해부, 재건법 등)
```

## 작성 요령
- 단계 경계 규칙은 "주석자 둘이 같은 프레임을 고를 수 있을 만큼" 구체적으로. 모호하면 일치도가 떨어진다.
- 위험구조는 "보이면 분할할 수 있는가(영상에 경계가 있는가)"와 "위치만 알면 되는가"를 구분 →
  SemS/InS vs ObD(점·중심) 선택의 근거.
- 안전 확인지점이 문헌으로 정의돼 있지 않으면 연구팀 합의(Delphi 등)를 별도 단계로 계획하고 범위 밖(퍼지 정답)임을 명시.
