# 수술영상 CV 과제 카탈로그 (수술 공통)

표기: **[MR]** Metrics Reloaded 근거 · **[적용]** 이 스킬의 적용 판단(데이터로 확인) · **[외부]** MR 범위 밖, 다른 근거.

## 1. 과제 → 문제유형 → 권장 지표 묶음(출발점)

| CV 과제 | 문제유형 | 핵심 지표 묶음 | 주의 |
|---|---|---|---|
| 단계(phase/step) 인식 | ImLC(프레임) + 시간적 측면은 범위 밖 | 비디오별 Accuracy·단계별 Precision/Recall/Jaccard(또는 F1) → 비디오 간 평균±SD; BA 또는 MCC + 혼동행렬; 구간 지표(segmental F1@k, edit score) [외부] | online/offline, 평활 사용 여부, 비디오별 vs 풀링, relaxed 평가 금지, 여러 seed·SD 보고 [외부: Funke 2023]; 단계 혼동 비용이 불균등하면 EC [MR] |
| 안전 확인지점 판정(CVS, MPO 노출, RLN 확인 등) | ImLC(기준별 이진 + 전체) | 연구·감사 목적이면 AUROC(주지표 후보), 경고 목적이면 고정 운영점(Sens 목표에서 PPV·시간당 오경보)을 주지표로; AP, 보정; 실제 결정에 쓰면 Net Benefit | 시점 기준점·창 사전 정의, 정답 암시 단서 배제(RF14), 수술당 판정 1개면 풀링+cluster CI(RF16); 합의 정답 생성은 범위 밖 [MR §6] |
| 기구 존재 | ImLC(라벨별 이진) | 라벨별 AUROC + AP, 결정 규칙 시 Sens/PPV@목표 | 드문 기구는 AP의 기준선(유병률) 함께; 로봇 UI 오버레이에 기구명이 표시되면 누설 |
| 기구 검출(bbox) | ObD | 위치 기준(Box IoU 등, 임계 명시) + Greedy-by-Score + AP 또는 FROC | Accuracy/Spec/AUROC 금지 [MR]; 가는 샤프트는 박스 근사 불량 → 점·마스크 기준 [MR S8] |
| 기구 분할 | 같은 종류 동시 출현 가능 → InS, 아니면 SemS | InS: AP(정의 명시) 또는 PQ + 개체별 DSC/NSD; SemS: DSC + NSD | SemS로 두면 거리 지표 금지(RF3) |
| 해부 장기 분할(큰 구조: 간, 위, 췌장 등) | SemS | DSC + NSD 또는 MASD | 경계가 지방에 묻히면 FP4.3.1 → NSD(τ) [MR] |
| 관형 위험구조 분할(혈관·담관·요관·신경) | SemS(이어진 나무는 한 구조, FP3.6) / 서로 다른 개체를 세야 할 때만 InS | DSC + clDice + 경계 지표; 연결성; 크기별 층화 | 작은 구조 DSC 불안정(P2.2); 위치만 필요하면 ObD(점·중심) 후보 [MR S1] |
| 작은 구조 검출(부갑상선, 림프절) | ObD | 점/중심 위치 기준 + AP/FROC | 정답이 병리 확인 없이 정해지면 퍼지 정답 |
| 박리면·절리면·안전/위험 영역 | SemS(퍼지 정답) | DSC/Fβ(놓침이 더 위험하면 재현율 쪽 가중) + 경계 지표 | 다중 주석자 정답 융합은 범위 밖 [MR §6]; 주석자 간 변동을 해석 기준으로 |
| 출혈·연기·누출 등 이벤트 | 프레임 ImLC / 이벤트 검출(범위 밖) | 프레임: AUROC/AP; 이벤트: 고정 오경보율에서 이벤트 Sensitivity, 탐지 지연 | 이벤트 정의(중증도 기준 — 간 절리 중 미세 삼출은 늘 있음)·매칭 시간창 사전 정의; 흡인기·클립·거즈 등 대응 동작이 정답 단서가 되는 누설 점검 [적용] |
| 림프절 station·박리 부위 인식 | ImLC 다중클래스(시간적) | 단계 인식과 동일 + EC(인접 station 혼동 경미) | station 경계 정의서 필수 |
| Action triplet / 동작 | ImLC 다중라벨 | 성분별·triplet별 AP, 평균 방식 명시 | "mAP" 이름만 쓰지 말고 공식 명시 [MR P3] |
| 형광(ICG) 관류·경계 | 경계는 SemS, 관류 정량은 회귀(범위 밖) | 경계: DSC+NSD; 정량: 오차·일치도 | 모드별 층화 |
| 술기 평가(GEARS, OSATS 등) | 회귀/서열 — 범위 밖(서열 범주면 ImLC+EC) | MAE, ICC·Bland–Altman, 순위상관; 서열이면 EC [MR] | 정답 평가자 간 ICC 함께 |
| 남은 수술시간 예측 | 회귀 — 범위 밖 | MAE(진행 구간별), 조기 구간 오차 | 시점별 층화 [외부] |
| 체외 장면·화면 품질 판정(개인정보 전처리) | ImLC | Sensitivity 우선(놓치면 개인정보 노출) + PPV | 목표값 기반 결정 규칙(FP2.6) — 예: Sens ≥ 목표에서 Spec |
| 기구 추적·키포인트·깊이·3D 재구성 | 범위 밖 | 과제별 표준 지표 + 근거 문헌 | 한계에 명시 |
| 비디오 → 술후 결과 예측 | ImLC(비디오 수준) + 임상예측모형 | AUROC, 보정(slope·intercept·Brier), Net Benefit | TRIPOD+AI [외부] |
| 실시간 보조 공통 | 비참조 | fps, 지연(ms), 하드웨어 | [MR 비참조 단계] |

## 3. 범위 밖 과제 처리
1. 설계서 한계에 "Metrics Reloaded 범위 밖" 명시, MR만으로 정당화하지 않는다(RF13).
2. 단계 인식: 프레임 부분은 MR ImLC 원칙, 시간적 부분은 구간 지표 + 계산 방식 명시 [외부: Funke 2023].
3. 회귀: 오차 + 일치도 + 정답 신뢰도.
4. 퍼지 정답: 다중 주석자 융합 방법을 사전에 정하고 별도 근거 인용.

## 4. 분석단위·분할 체크
- 표본수 단위 = 환자(수술); 희귀 사건이 목표면 사건 수.
- 같은 환자의 분할 저장 비디오는 같은 split.
- 기관·플랫폼·술자 경험·난이도·술식 유형 메타데이터 → 하위군·외부검증.
- 술자·기관이 2–3개뿐이면 그 단위 leave-one-out·cluster bootstrap은 무의미 → 기술통계.
