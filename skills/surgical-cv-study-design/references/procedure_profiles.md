# 수술 프로파일 (초안 — 연구팀 외과의가 확정)

각 프로파일은 **설계의 출발점일 뿐**이다. 단계 정의·위험구조·안전 확인지점은 기관 술식과 연구 질문에 맞게
연구팀이 확정한다. 공개 데이터셋은 `sources.md`의 검증 상태를 확인하고 인용한다.

공통 양식: ① 단계(phase) 초안 ② 핵심 해부·위험구조 ③ 안전 확인지점 ④ AI가 줄이려는 사건 ⑤ 대표 CV 과제
⑥ 수술 특이 fingerprint ⑦ 관련 공개 데이터 ⑧ 주의점.

## 1. 간절제 (복강경·로봇; 개복은 approach_modifiers 개복 항목 추가 적용)
1. **단계 — 술식별로 따로 정의**(공통 핵심 + 조건부 단계):
   - 해부학적 절제(구역·분절): 탐색·포트 → 간 유리 → 유입혈류 처리(글리슨 지경 또는 간문부 박리, ±Pringle) →
     절리선 표시(ICG 음성/양성 염색, 허혈 경계, 수술 중 초음파) → 간실질 절리 → 간정맥·지경 처리 → 지혈·담즙누출
     확인 → 검체 회수.
   - 비해부학적(wedge) 절제: 유입혈류 처리·경계 표시 단계가 없거나 짧음 → **조건부 단계**로 정의하고, 단계별
     지표는 그 단계가 있는 비디오에서만 계산(없는 비디오에서의 오탐은 따로 보고).
   - 절리와 지혈은 짧게 번갈아 나타남 → phase보다 step 수준 라벨과 구간 지표가 유용.
2. **위험구조**: 중간·좌·우 간정맥과 분지, 단간정맥·하대정맥 분지, 남는 간의 글리슨 지경과 담관, 우측 부신·횡격막.
3. **안전 확인지점(가설)**: 간절제에는 담낭절제의 CVS 같은 **합의된 확인지점이 없다**. "절리면이 구역 경계·간정맥
   주행을 따르는가", "남는 쪽 유입·유출 보존 확인"은 연구 가설로 쓰고, 쓰려면 연구팀 합의(Delphi 등)를 먼저 계획.
4. **사건**: 절리 중 출혈(미세 삼출은 늘 있으므로 중증도 기준 필수), 담즙누출, 공기색전, 남는 간의 허혈·울혈.
5. **CV 과제**: 노출된 간정맥·글리슨 구조 분할(관형), 절리면/구역 경계 분할(ICG 영상), 출혈 이벤트, 단계·step 인식.
6. **fingerprint와 핵심 한계**:
   - **보이는 것만 정답이 된다**: 간정맥·글리슨은 CUSA·clamp-crush로 실질이 열린 뒤에야 보인다. 영상만으로는
     노출 전 경고를 학습·평가할 수 없음 → 노출 전 예측은 수술 중 초음파·CT 정합이 필요(범위 밖). 주장을
     "노출된 구조 인식"으로 한정.
   - FP3.3 관형 TRUE, FP3.1 작은 분지 TRUE, 출혈·연기·CUSA 미스트로 가림 많음, 빈 정답 프레임 매우 많음(절리
     전·wedge) → 2층 평가(SKILL 원칙 6).
   - ICG 형광: 모드 전환 = 영상 도메인 변화(모드별 층화). 음성 염색 경계는 주입 후 시간에 따라 흐려지고 퍼짐
     → 시간 의존 퍼지 정답, 주입 후 경과시간을 메타데이터로.
   - FP4.3.1 절리면 경계 변동 큼.
7. **공개 데이터**: P2ILF(간 표면 랜드마크·2D–3D 정합 — 혈관·단계 라벨은 없어 외부검증용으로는 제한적),
   PmLR50(phase+Pringle, 공개 미확인). 혈관·단계 라벨이 있는 공개 데이터는 찾지 못함.
8. **주의**: 해부학적 vs wedge, 구역(S1–S8, 특히 미상엽·후구역은 시야·술기가 크게 다름), 플랫폼(로봇/복강경)을
   층화 변수로. 기관마다 플랫폼·술식 비율이 다르면 기관 간 비교가 술식 비교로 오염된다.

## 2. 간이식 (공여자 간절제 / 수혜자)
1. **단계(수혜자, 주로 개복)**: 개복·박리 → 전간절제(hepatectomy) → 무간기 → 간정맥(피기백 등) 문합 →
   문맥 문합 → 재관류 → 간동맥 문합 → 담관 문합 → 지혈·폐복. **공여자(복강경·로봇)**: 간 유리 → 간문부
   박리 → 담관 절단 위치 결정(ICG 담관조영 등) → 실질 절리 → 혈관 처리·적출.
2. **위험구조**: 공여자 — 남는 쪽 담관·간동맥·문맥 분지, 간정맥 배액; 수혜자 — 문합 부위.
3. **안전 확인지점**: 공여자 담관 절단 위치, 재관류 후 혈류.
4. **사건**: 공여자 담관 합병증, 출혈, 문합 협착·혈전.
5. **CV 과제**: 단계 인식(긴 수술 — 비디오 길이 편차 큼), 담관/혈관 분할(관형), 형광 담관조영 경계, 문합 단계 이벤트.
6. **fingerprint**: 수혜자 수술은 **개복 영상**(`approach_modifiers.md` 개복 항목) → 카메라 이동·사람 노출 많음.
7. **공개 데이터**: 확인된 것 없음.
8. **주의**: 증례 수가 적어 다기관 협력이 사실상 필수, 단계 길이 극단적 불균형.

## 3. 췌십이지장절제(PD)·원위췌절제(DP) (개복·복강경·로봇)
1. **단계(PD)**: 탐색 → Kocher → 위결장인대·SMV 노출 → 담낭·총담관 처리 → GDA 처리 → 위/십이지장 절단 →
   췌장 절단(PV/SMV 터널) → 공장 처리 → 췌장 갈고리돌기·SMA 박리 → 재건(췌장·담관·위 문합).
2. **위험구조**: SMA, SMV/PV, 총간동맥, GDA, 변이 우간동맥(SMA 기시), 제1공장정맥.
3. **안전 확인지점**: GDA 결찰 전 클램핑으로 간동맥 흐름 확인, SMA 좌측 경계 확인.
4. **사건**: 주요 혈관 손상·출혈, 췌장루(POPF), 지연 출혈.
5. **CV 과제**: 혈관 분할(관형·작음), 단계 인식, 박리면(SMA 주위) 분할, 출혈 이벤트.
6. **fingerprint**: 관형 TRUE, 혈관 가림·지방 조직 많음, 재건 단계 길이 큼.
7. **공개 데이터**: 확인된 것 없음.
8. **주의**: 변이 해부(대체 우간동맥 등)가 정답 정의에 영향 → 변이 여부를 메타데이터로.

## 4. 위절제 (복강경·로봇 원위/전절제)
1. **단계**: 탐색 → 대망 박리·좌위대망혈관(4sb) → 우위대망혈관(6) → 우위동맥(5)·십이지장 절단 → 상췌장 림프절
   (8a, 12a, 7, 9, 11p) → 소만(1, 3) → 위 절단 → 재건(B-I, B-II, Roux-en-Y, 식도공장).
2. **위험구조**: 췌장(상연), 총간동맥·비장동맥·좌위동맥, 문맥, 비장.
3. **안전 확인지점**: 상췌장 박리 시 췌장 압박·손상 회피, 좌위동맥 결찰 전 구조 확인.
4. **사건**: 췌장 손상→췌장루, 혈관 손상, 림프절 박리 불충분.
5. **CV 과제**: 단계/림프절 station 인식(ImLC, 다중클래스), **췌장 분할**(손상 경고), 혈관 분할, 기구 검출.
6. **fingerprint**: 췌장 경계가 지방에 묻혀 FP4.3.1 큼, 경계 중요(FP2.1), station 단계 혼동 비용 불균등(FP2.5.2 → EC).
7. **공개 데이터**: 공개 데이터 확인 안 됨(sources.md) → 국내 다기관 협력이 현실적 경로.
8. **주의**: 원위/전절제·재건법별 단계 차이 → 술식을 층화 변수로.

## 5. 대장 — 우측결장 CME/CVL, 좌측결장·직장 TME
1. **단계(직장)**: 내측 접근·IMA 박리 → IMA/IMV 결찰 → 좌측결장 유리(비장만곡) → 직장간막 후방·측방·전방 박리
   (TME) → 직장 절단 → 문합. **우측**: 회결장 혈관 → SMV 노출(Henle trunk) → 결장 유리 → 문합.
2. **위험구조**: 좌측 요관·성선혈관, 상·하하복신경총, 골반신경총, 십이지장(우측), Henle trunk 분지.
3. **안전 확인지점**: IMA 결찰 전 요관·신경 확인, TME 박리면("holy plane") 유지.
4. **사건**: 요관 손상, 자율신경 손상(배뇨·성기능), 직장간막 손상(CRM 양성), 문합누출.
5. **CV 과제**: 박리면 분할(경계·퍼지 정답), 요관·신경 분할(관형·작음), 단계 인식, 해부 장기 분할.
6. **fingerprint**: 박리면 정답은 본질적으로 모호(퍼지 → MR 범위 밖), 관형 TRUE, 골반 깊은 시야로 조명 불균일.
7. **공개 데이터**: HeiCo/ROBUST-MIS(30편, phase·기구·instance 분할), DSAD(로봇 직장 32편, 요관·IMA 등 11구조 마스크).
8. **주의**: 직장 수술은 개복/복강경/로봇/TaTME 혼재 → 접근법 층화.

## 6. 식도절제 (흉강경·로봇 RAMIE)
1. **단계**: 흉부 — 식도 유리, 좌·우 반회후두신경 주위 림프절 박리, 기관분기부, 흉관 처리 → 복부 — 위관 형성 →
   경부/흉강 내 문합.
2. **위험구조**: 좌·우 반회후두신경(RLN), 흉관, 기관·기관지 막양부, 대동맥.
3. **안전 확인지점**: RLN 주위 박리 시 신경 확인·열손상 회피.
4. **사건**: RLN 마비, 유미흉, 기도 손상, 문합누출.
5. **CV 과제**: RLN 분할·검출(관형·작음), 단계 인식, 에너지기구–신경 근접(거리 → 회귀/범위 밖).
6. **fingerprint**: 작은 관형 구조, 신경 경계 FP4.3.1 큼, 체위·시야가 흉부/복부 단계로 크게 바뀜.
7. **공개 데이터**: RAMIE 단계 연구(27편)는 있으나 공개 확인 안 됨.

## 7. 서혜부 탈장 (TAPP / TEP / 로봇)
1. **단계**: 복막 절개·flap(TAPP) 또는 전복막 공간 형성(TEP) → 치골·Cooper 인대 노출 → 하복벽혈관 확인 →
   myopectineal orifice 노출 → 탈장낭 처리(정삭 parietalization) → 메쉬 거치·고정 → 복막 봉합(TAPP).
2. **위험구조**: 외장골 혈관("triangle of doom"), 대퇴·음부대퇴·외측대퇴피신경("triangle of pain"), 정관·고환혈관,
   corona mortis.
3. **안전 확인지점**: 메쉬 거치 전 myopectineal orifice 전체 노출(문헌상 'critical view of the MPO' 개념 — 인용 전 원문 확인).
4. **사건**: 재발(불충분한 노출·메쉬 크기), 만성 통증(신경 손상·고정), 혈관 손상.
5. **CV 과제**: 안전 확인지점 판정(ImLC), 위험 영역 분할(퍼지), 단계 인식, 메쉬 위치 평가.
6. **fingerprint**: 짧은 수술·표준화된 단계 → 단계 인식 쉬움, 위험 "영역"은 구조가 아니라 해부학적 삼각형이라
   경계 정답이 모호.
7. **공개 데이터**: 공개 데이터 확인 안 됨(대규모 비공개 셋만 보고됨).

## 8. 충수절제
1. **단계**: 탐색 → 충수 유리·간막 처리 → 기저부 결찰·절단 → 회수 → 세척.
2. **위험구조**: 맹장 기저부, 회장, 우측 요관(드묾).
3. **CV 과제**: 염증 등급 분류(서열형 ImLC → EC, `task_catalog.md`), 천공 여부, 단계 인식.
4. **fingerprint**: 등급 정답 평가자 간 변동 큼, 클래스 혼동 비용 불균등(FP2.5.2).
5. **공개 데이터**: Appendix300(330 영상, 염증 등급; 수량은 출처마다 다름).

## 9. 갑상선·부갑상선 (개방 / 내시경·로봇 BABA·TOETVA)
1. **단계**: 피판 형성 → 갑상선 상극(상갑상선 혈관) → 측방 박리 → RLN 확인·추적 → 부갑상선 확인·보존 →
   Berry 인대 처리 → 협부/반대측.
2. **위험구조**: RLN, 상후두신경 외지, 부갑상선(혈류).
3. **안전 확인지점**: RLN 육안 확인(±신경 감시), 부갑상선 확인(근적외선 자가형광 NIRAF 등).
4. **사건**: RLN 마비, 저칼슘혈증(부갑상선 손상), 출혈.
5. **CV 과제**: RLN 분할(관형·작음), 부갑상선 검출(ObD, 작은 구조, 자가형광 영상), 단계 인식.
6. **fingerprint**: FP3.1 작음, 부갑상선은 정답 불확실(병리 확인 없으면 퍼지), 자가형광은 별도 영상 도메인.
7. **주의**: 개방 수술이 많아 개복 수정사항 적용(손 가림, 시야 변동).

## 10. 비만수술 (Sleeve, RYGB)
1. **단계(RYGB 예)**: 탐색 → 위 소낭 형성 → 공장 측정·위공장 문합 → 공장공장 문합 → 간막 결손 봉합.
2. **위험구조·사건**: His각 부위 누출, 비장 손상, 협착, 내부 탈장.
3. **CV 과제**: 단계·step 인식, 문합 단계 이벤트, 기구.
4. **공개 데이터**: MultiBypass140(2기관 140편, 12 phase·46 step, CC BY-NC-SA), Bypass40(논문 확인, 공개 여부 미확인).

## 11. 로봇 근치적 전립선절제 (RARP)
1. **단계**: Retzius 공간 → 방광경부 박리 → 정낭·정관 → 후방 박리 → 신경혈관다발(NVB) 보존 → 첨부·요도 절단 →
   방광요도 문합.
2. **위험구조**: NVB, 외요도괄약근, 직장.
