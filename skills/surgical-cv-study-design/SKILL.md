# 범용 수술영상 CV 연구 설계

목표: 어떤 수술이든 **① 수술을 먼저 이해하고(수술 프로파일) → ② 임상 질문을 CV 과제로 바꾸고 →
③ Metrics Reloaded 원칙으로 지표·데이터 설계를 고정**한다. 산출물은 프로젝트 폴더의
`study_design/<procedure>_cv_design.md` 한 문서(양식: `references/design_template.md`).

## 라우팅
- **담낭절제술** → `/cholecystectomy-vision-study-design` (CVS·담낭관 등 심화 규칙이 있음). 이 스킬은 쓰지 않는다.
- 그 외 모든 수술 → 이 스킬.
- 이미 학습된 모델의 성능 계산·감사 → `/model-assessment`.

## 원칙 (어기면 설계 실패)

1. **수술이 먼저, 모델은 나중.** 수술 프로파일 없이 지표를 고르지 않는다. "이 AI가 어떤 합병증·실수를
   줄이거나 어떤 판단을 돕는가"가 문장으로 나와야 Step 2로 간다.
2. **질문 하나 = 권고 하나.** 질문별로 fingerprint와 지표 묶음을 따로 만든다. 다중 라벨은 라벨별 이진 문제로.
3. **문제유형부터 맞춘다(S1, P1).** 서로 다른 개체를 세거나 구분해야 하는 같은 종류 구조(기구 2개, 림프절
   여러 개)는 SemS가 아니라 InS/ObD. 하나로 이어진 혈관·관 나무(간정맥 분지 등)는 한 구조로 보고 SemS(+FP3.6
   비연결 가능)로 둔다 — 분지를 개체로 나누는 InS는 정의가 모호하다.
4. **단일 지표 금지, 주지표는 질문당 하나.** 겹침+경계, 판별+보정, 고정임계+다중임계를 짝짓되 주지표는
   질문당 1개 사전 지정(구조가 여럿이면 구조별 + 다중성 처리 명시). 수학적 동치 지표 중복 금지.
5. **분석단위는 환자/수술.** 분할·CI는 환자(수술) 단위 cluster bootstrap(또는 GEE·혼합모형). 분할·검출
   지표는 프레임→비디오→전체, 분류 지표는 비디오 내 양·음성이 충분할 때만 비디오별, 아니면 풀링+cluster CI.
6. **빈 정답/빈 예측 규칙과 테스트 프레임 표본추출을 미리 쓴다.** 구조가 보이는 프레임만 평가하지 않는다.
   빈 정답이 흔한 분할 과제는 **2층 평가**로 설계한다: (a) 모든 프레임에서 구조 존재 판정(ImLC: AUROC/AP,
   빈 정답 프레임의 오탐률), (b) 정답에 구조가 있는 프레임에서만 분할 지표(DSC·clDice·NSD). 정답·예측이
   모두 빈 프레임은 (a)에서 정답으로 세고 (b)에서는 제외 — NaN을 최악값으로 두는 규칙을 그대로 쓰면 올바른
   빈 예측이 0점이 된다. 어느 규칙을 쓰는지 설계서에 명시.
7. **정답 품질을 숫자로.** 주석자 수·자격·판정 방식·일치도를 계획하고, 결과 자릿수를 일치도에 맞춘다.
   블라인드 재주석은 AI 초안 없이 시작했는지 명시(같은 초안 공유는 일치도를 부풀림).
8. **시점·누설을 정의한다.** 판정 시점이 있는 과제(안전 확인지점, 이벤트)는 기준점·창을 정하고 정답을
   암시하는 단서를 입력에서 배제. 장래 실시간 사용이면 지금부터 인과적(online) 평가를 하고, **두 가지 지연을
   구분**한다: 프레임 처리량(≤1000/fps ms, 예: 30 fps면 33 ms)과 임상적 경고 지연(사건 발생→경고까지
   허용 시간, 임상적으로 정함 `[결정 필요]`).
9. **접근법이 영상을 바꾼다.** 개복(카메라 이동·손 가림·사람 노출), 로봇(UI 오버레이·스테레오·키네마틱스),
   단일공(시야·기구 배치), 내시경/현미경(초점·확대)의 차이를 fingerprint와 개인정보 계획에 반영한다.
10. **Metrics Reloaded 범위 밖은 범위 밖이라고 쓴다.** 시간적(phase 전환), 회귀(술기 점수), 추적,
    깊이/3D, 퍼지·다중관찰자 정답은 대체 근거를 쓰고 한계에 적는다.
11. **수치를 지어내지 않는다.** τ·IoU 임계·표본수·유병률·단계 정의가 불확실하면 `[결정 필요]`.
    수술 프로파일의 단계 정의·위험구조도 **연구팀 외과의가 확정**하기 전에는 초안이다.

## 워크플로

### Step 0 — 입력 확인
수술명, 접근법·플랫폼, 기관·술자 수, 비디오 수·길이·해상도·fps, 임상 질문, 사용 시점(online/offline),
정답 형태. **기관×플랫폼×술식 교차표**를 먼저 만든다 — 기관마다 플랫폼이나 술식이 다르면 "기관 간 외부검증"이
실제로는 플랫폼·술식 비교가 되므로 설계 전 차단 요인으로 다룬다. 없으면 한 번에 묻고, 물을 수 없으면 가정을 세워 `[결정 필요]`로 기록. 사용자가 출력 경로를
주면 그 경로를 쓴다.

### Step 1 — 수술 프로파일 (이 스킬의 앞단 핵심)
1. `procedure_profiles.md`에서 해당 수술을 찾는다. 없으면 `procedure_profile_template.md`로 새로 쓴다.
2. 프로파일 항목을 이 연구 맥락으로 확정한다:
   - **단계 온톨로지**: SAGES 시간 계층(수술 > phase > step > task > action). 공개 데이터셋 온톨로지가
     있으면 맞춰 비교 가능성을 확보하고, 다르면 대응표(mapping)를 만든다.
   - **핵심 해부·위험구조**와 손상 시 결과, **안전 확인지점**(담낭절제의 CVS에 해당하는 것: 예: 간절제의
     절리면·글리슨 확인, 대장의 IMA/IMV 결찰 전 요관 확인, 갑상선의 RLN 확인).
   - **AI가 줄이려는 사건**(합병증·실수·지연)과 그 빈도 — 희귀하면 이벤트 수가 표본수를 결정한다.
   - 기구 목록, 영상 특성(`approach_modifiers.md`), 개인정보 위험 구간.
   - 관련 공개 데이터셋(외부검증·전이학습 후보) — `sources.md`에서 검증 상태 확인.
3. 프로파일 요약을 설계서 §0에 넣는다.

### Step 2 — 임상 질문 → CV 과제 → 문제유형 (S1)
`task_catalog.md` §1로 각 질문을 ImLC / SemS / ObD / InS / 범위 밖으로 매핑하고 근거를 한 줄씩 적는다.

### Step 3 — Problem fingerprint
`metrics_reloaded_core.md` §2 항목을 질문별로 채운다. 시작값은 `task_catalog.md` §2 + 수술 프로파일의
"수술 특이 fingerprint" + 접근법 수정사항. **반드시 이 데이터로 확인**(빈 프레임 비율, 구조 크기 분포 등).

### Step 4 — 지표 선택
`metrics_reloaded_core.md` §3–4 경로 → 응용특이 지표(관형 구조 clDice, 부피, 시간적 지표는 외부 근거) →
비참조 지표(속도·지연). 지표마다 선택 근거 FP 코드를 남긴다. 작은 구조는 DSC 불안정(P2.2) → 경계·검출
관점 지표와 크기별 층화. Net Benefit은 실제 확률기반 의사결정이 있을 때만. 경고형 과제는 고정 운영점
(사전 지정 Sensitivity에서 PPV, 시간당 오경보)이 임상 의미가 크므로 AUROC 대신 주지표로 검토. clDice·연결성
지표가 참조구현에 없으면 자체 구현 + 단위 테스트를 계획.

### Step 5 — 지표 적용 계획
MONAI MetricsReloaded 참조구현(버전 고정), 계층 집계, NaN 규칙, 클래스별+요약, 기관·플랫폼·술자 경험·
난이도 하위군, paired 비교, 원시 분포 시각화, 혼동행렬, 여러 seed, 모든 지표에 CI(100%·0% 같은 경계값은
정확 구간 사용 — bootstrap은 폭 0이 됨; 단 정확 구간은 환자 군집을 무시하므로 설계효과로 보정하거나 근사임을 명시).

### Step 6 — 데이터·주석·분할
- 주석 정의서(단계 경계 규칙, 구조 정의, 예시 프레임), 주석 그리드 간격과 보간 여부를 출처 태그로 남김.
- 이중주석 비율·판정 방식, AI 초안 사용 시 블라인드 조건.
- 분할: 환자 단위; 다기관이면 기관 단위 외부검증, 단일기관이면 시간적 분할 + 한계 명시.
- 개인정보: 체외 장면·사람·화면 오버레이 삭제 규칙과 그로 인한 단계 편향(준비·종료 단계 손실) 기록.
- 2D 거리·NSD τ는 픽셀 단위 → 해상도 고정, τ는 이중주석 프레임의 주석자 간 경계거리(예: 중앙값·95백분위)에서
  도출, τ 민감도 분석. 혈관처럼 폭이 몇 픽셀인 구조는 τ가 폭과 비슷해지므로 clDice를 주지표 후보로.
- 픽셀 주석 예산: 전 프레임 마스크는 불가능 → 환자·단계별 층화 표본(빈 정답 프레임 포함)으로 주석하고,
  주지표의 환자 단위 CI 폭 목표로 프레임·환자 수를 정한다.
- **보이는 것만 정답이 된다**: 노출 전 구조(실질 속 혈관 등)는 영상 정답이 없으므로 "노출 전 경고"는 영상만으로
  평가할 수 없다(수술 중 초음파·CT 정합 필요 — 범위 밖). 주장 범위를 "노출된 구조 인식"으로 한정.
- 개인정보 처리: 삭제는 단계 분포를 바꾸고 시간축에 구멍을 낸다 → 시간적 과제면 삭제 대신 블러·마스킹을
  우선 검토하고, 삭제했다면 구멍 처리 규칙을 사용자에게 명시.

### Step 7 — 설계서 작성과 레드플래그 점검
`design_template.md`로 작성하고 아래를 점검해 표로 붙인다.

| 코드 | 레드플래그 |
|---|---|
| RF0 | 수술 프로파일 없음 / AI가 줄이려는 사건이 정의되지 않음 |
| RF1 | 프레임 단위 무작위 분할 / 프레임을 독립 표본으로 CI |
| RF2 | 분할 과제에 Dice(또는 IoU)만 — 경계 지표 없음 |
| RF3 | 같은 클래스 다중 개체인데 SemS + 거리기반 지표 |
| RF4 | 검출 과제에 Accuracy/Specificity/AUROC |
| RF5 | 불균형 분류에 Accuracy 단독 헤드라인 |
| RF6 | 확률이 의사결정에 쓰이는데 보정 평가 없음 |
| RF7 | 빈 정답/빈 예측 처리 규칙 미기재 |
| RF8 | 주석자 간 일치도 계획 없음 / 자릿수 과잉 / 블라인드 조건 불명 |
| RF9 | 시간축 과제인데 online/offline·기준점·창 미정의; phase면 구간 지표 없음 |
| RF10 | 실시간 목적(장래 포함)인데 인과적 평가·지연 미평가 |
| RF11 | 임계값·후처리를 테스트셋에서 결정 |
| RF12 | 외부검증도 시간적 분할·한계 기술도 없음 / 하위군 계획 없음 |
| RF13 | 범위 밖 과제를 Metrics Reloaded 근거로만 정당화 |
