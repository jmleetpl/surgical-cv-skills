## 1. 함정 분류 (sister paper의 taxonomy)

| 코드 | 함정 | 대응 단계 |
|---|---|---|
| **P1** | 문제유형을 잘못 고름(예: 모든 개체를 찾았는지가 중요한데 SemS 지표 사용) | Step 1 fingerprint + 유형매핑 |
| **P2** | 지표 선택 부실 | Step 2 지표선택 |
| P2.1 | 영역 관심사 무시: 경계·부피·중심선 중요성, 클래스 오분류 심각도 불균등(서열형), 과/과소분할 비대칭, 신뢰도·비용편익 | |
| P2.2 | 대상 구조 성질 무시: 작은 크기(1픽셀 차이가 Dice를 크게 흔듦), 복잡한 형태·관형, 크기 변동, 겹침/접촉, 비연결 | |
| P2.3 | 데이터셋 성질 무시: 클래스 불균형, 작은 표본(보정지표 편향), 정답 품질·공간 이상치(HD에 치명적), 빈 정답 | |
| P2.4 | 알고리즘 출력 성질 무시: 겹치는 예측, 빈 예측(0으로 나눔), 확률 점수 부재 | |
| **P3** | 지표 적용 부실 | Step 3 지표적용 |
| P3.1 | 구현 비표준(라이브러리마다 값이 다름) | 참조구현 사용 |
| P3.2 | 집계 부실(데이터셋 전체 픽셀 한꺼번에 평균 — 예: TorchMetrics 기본 DSC 전역평균; 계층구조 무시) | 이미지별 계산 후 집계 |
| P3.3 | 순위 부실(DSC+IoU처럼 관련 지표 동시 사용, 동의어 중복, 순위 불확실성 무시) | |
| P3.4 | 보고 부실(박스플롯만, 최고 run만, CI/SD 없음, 비결정성 무시) | |
| P3.5 | 해석 부실(임상적으로 무의미한 미세 차이로 순위, 상·하한이 없는 지표) | |

교훈 사례: 셀 instance segmentation 챌린지가 "mAP"라는 이름으로 사실상 IoU 공식을 정의했고 그 오용이
후속 연구로 전파됨 → **지표 이름이 아니라 공식을 명시**한다.

## 2. Problem fingerprint 항목

표기 FPX.Y. 문제유형에 따라 일부 항목만 해당한다(예: 구조물 크기는 ImLC에 무관).

**FP1 문제유형** — ImLC(이미지 수준 분류) / SemS(semantic segmentation) / ObD(object detection) / InS(instance segmentation)

**FP2 영역 관심사**
- FP2.1 경계가 특히 중요 · FP2.2 부피가 특히 중요 · FP2.3 중심/중심선이 특히 중요
- FP2.4 필요한 위치정밀도(위치만 / 대략 윤곽 / 정밀 윤곽)
- FP2.5 오류 벌점 방식
  - FP2.5.1 클래스별 관심 불균등 · FP2.5.2 클래스 혼동 심각도 불균등(서열형)
  - FP2.5.3–2.5.4 오분류 비용 제공 가능 / 유병률과 중요도 불일치 `[VERIFY: 원문 번호 표기가 섹션마다 다름 —
    설계서에는 번호 대신 내용(예: "오분류 비용 제공 가능")으로 적는다]`
  - FP2.5.5 클래스 불균형 보정 원함 · FP2.5.6 공간 이상치 벌점 방식(존재 여부 vs 거리)
  - FP2.5.7 주석 부정확성 보정 원함 · FP2.5.8 중복 할당 벌점 여부
- FP2.6 확률→결정 규칙: 목표값 기반(예: Sens=0.95에서 Spec) / 최적화 기반(별도 split) / argmax /
  비용편익 기반(보정된 점수+비용 필요) / 결정 규칙 없음(다중임계 지표만). SemS 외에는 선택사항.
- FP2.7 보정: FP2.7.1 보정 평가 원함 · FP2.7.2 비교 보정 평가 · FP2.7.3 출력 해석가능성 평가

**FP3 대상 구조**
- FP3.1 격자 대비 작은 구조 · FP3.2 크기 변동 큼 · FP3.3 관형(tubular) · FP3.4 계층적 라벨/사전지식 준수
- FP3.5 겹치거나 맞닿을 수 있음 · FP3.6 비연결 구조 가능

**FP4 데이터셋**
- FP4.1 심한 클래스 불균형 · FP4.2 데이터 유병률이 목표 모집단을 반영
- FP4.3.1 주석자 간 변동 큼 · FP4.3.2 정답에 공간 이상치 가능 · FP4.4 정답 형태(마스크/박스/점)
- FP4.5 테스트 사례 비독립(계층 데이터) · FP4.6 정답에 대상 없음 가능

**FP5 알고리즘 출력**
- FP5.1 예측 확률 점수 있음 · FP5.2 빈 예측 가능 · FP5.3 무효 예측 가능 · FP5.4 예측끼리 겹침 가능

## 3. 문제유형별 지표 선택 경로

### ImLC (이미지/프레임/클립/비디오 단위 분류)
1. **다중클래스 counting 지표(S2)** — 결정 규칙이 있을 때.
   - 혼동 심각도 불균등(FP2.5.2)+비용 있음 → **EC(Expected Cost)** 기본. Weighted Cohen's Kappa는 비권장
     (두 평가자 대칭 상황용, 이차가중 시 역설적 결과).
   - 유병률이 목표 모집단 반영(FP4.2)+불균형 보정 불필요 → Accuracy 가능.
   - 그 외 유병률 독립 지표: 모든 클래스를 동등하게 → **BA**; 목표 유병률 반영 → EC;
     높은 PPV·NPV 보장 필요 → **MCC**; 클래스 관심 불균등 → ECN(정규화 EC).
   - 클래스 수가 감당 가능하면 **혼동행렬 전체** 보고.
2. **클래스별 counting 지표(S3, one-vs-rest)** — FP2.6에 따라:
   목표값 규칙 → Metric@(Target=값) / 비용편익(이진) → **Net Benefit**(위험 관점) 또는 EC(비용 관점) /
   최적화·argmax → Sensitivity, LR+, Fβ. (Sensitivity만 최대화하도록 임계값을 고르면 "모두 양성"이라는
   자명한 해로 수렴하므로, 유병률이 목표 모집단과 다를 때(FP4.2 거짓)는 LR+로 최적화)
3. **다중임계 지표(S4)** — 항상 권장, 클래스별. 기본 **AUROC**(유병률 독립). 희귀 클래스가 초점이면
   **AP**(유병률 의존, 예측값 반영).
4. **보정(S5)** — FP2.7.1이면. §4 S5 참조.

### SemS (픽셀 수준 분할)
- **이미지별로 계산 후 이미지 간 집계**(픽셀은 상관됨). DSC = 픽셀 수준 F1.
1. **겹침 지표(S6)** — 기본 사용. 단, 구조가 일관되게 작고(FP3.1) 정답이 잡음 많으면(FP4.3.1) 재고.
   DSC 기본(IoU와 사례별 단조관계라 정보가 중복 — 둘 중 하나만; 단 사례 평균 후 모델 순위는 달라질 수 있음), FP/FN 가중 다르면 Fβ, **관형(FP3.3) → clDice**(DSC와 병행 가능).
2. **경계 지표(S7)** — 일반적으로 추가.
   - 주석 부정확성 보정 원함(FP2.5.7) → **NSD**(허용오차 τ 명시) 기본.
   - 존재 기반 벌점 → NSD, 작은 윤곽 오류도 중요하면 Boundary IoU.
   - 거리 기반 벌점 → **MASD** 기본(ASSD보다 수학적 장점, HD·백분위 HD보다 이상치에 덜 민감).
   - HD / X백분위 HD(HD95) / ASSD는 후보 풀에 있음. HD95를 고르는 정확한 분기 `[VERIFY: DG7.x]`.
3. **응용특이 추가** — 부피 중요(FP2.2) → 부피오차(절대/상대, symmetric RVD); 관형 → 연결성 지표;
   중심/형태 일치; 계층 준수(FP3.4).
4. 같은 클래스 다중 개체 가능 → **InS로 재정의**. SemS로 남기면 거리기반 지표 피함(엉뚱한 개체 경계와 비교).

### ObD (개체 검출)
- **TN이 없으므로 Accuracy·Specificity·AUROC 무효.** 혼동행렬 4칸 중 3칸 기반 지표만.
1. **위치 기준(S8)** — 대략 윤곽 → Box/Approx IoU; 위치만 → Center Distance, Mask IoU>0,
   Point inside Mask/Box; 관형 → Point inside Mask/Box/Approx.
   임계값: 작은(FP3.1)·크기변동 큰(FP3.2) 구조는 낮추고, 겹침/접촉(FP3.5)이면 높인다.
   박스는 복잡·다성분 형태를 잘 근사 못함.
2. **할당 전략(S9)** — 점수 있음(FP5.1) → **Greedy-by-Score** 기본; 없으면 Greedy-by-localization,
   Optimal(Hungarian), Overlap>0.5. 중복 할당 벌점(FP2.5.8) 결정.
3. **분류 지표** — 점수 있으면 다중임계 **AP**(표준화) 또는 **FROC Score**(해석 쉬움)가 주; counting 지표
   (목표값 있으면 PPV@Sens=값, 없으면 Fβ)는 보조. counting 단독은 점수가 없을 때만.
- 다중클래스면 모두 클래스별.

### InS (개체 분할)
1. 검출 지표: 위치 기준은 목표 분할 지표와 일관되게(예: NSD 기반) 또는 Boundary IoU / Mask IoU / IoR;
   할당·분류는 ObD와 동일, Fβ 대안으로 **PQ**(TP 개체 평균 IoU × F1).
   AP를 쓰면 **위치 기준·임계값(단일 또는 범위)·할당 전략·평균 방식(클래스/이미지)을 공식으로 명시** —
   이름만 "mAP"로 쓰면 문헌마다 다른 지표가 된다(§1 교훈 사례).
2. 분할 지표(선택): 매칭된 TP 개체별 S6/S7 지표 후 평균("개체별 DSC").
3. 일대일 매칭이 불가능할 만큼 밀집·복잡 → Rand Index, Variation of Information, split/merge 오류.

## 4. 하위결정 S1–S9 요약

- **S1 유형매핑:** 같은 유형 구조 여러 개 → ObD/InS; 겹침/접촉 → InS; 작은 구조 → ObD 고려.
- **S2 다중클래스:** EC vs WCK vs Accuracy vs BA vs MCC vs ECN (위 ImLC 1).
- **S3 클래스별 counting:** 목표값 지표 / NB vs EC / LR+ vs Sensitivity(FP4.2 거짓) / Fβ(FP4.2 참; InS는 PQ 대안).
- **S4 다중임계:** AUROC(ImLC 기본) / AP / FROC(ObD·InS 전용).
- **S5 보정:** 비교 평가(FP2.7.2) — 재보정 방법 비교: KCE·ECE-KDE 또는 Brier; 분류기 간 비교: 클래스 관심
  불균등이면 CWCE, 아니면 KCE/ECE-KDE; 전반 성능: proper scoring rule(Brier, NLL).
  해석가능성(FP2.7.3) — 기본 ECE-KDE + RBS + CWCE, top-label ECE는 드물게. 추가 후보: calibration
  slope, ECI, O:E ratio. 주의: 보정지표는 유병률 의존·소표본에서 편향. 잘 보정된 점수 ≠ 진짜 사후확률
  → 일부 전문가는 proper scoring rule(Brier)만 쓰자고 주장. 객체 수준 과제는 배경 클래스 제외, NLL 불가.
- **S6/S7:** SemS 1–2 참조. **S8/S9:** ObD 1–2 참조.

## 5. 집계·적용 규칙 (Extended Data Table 1 + Suppl. Note 2.3–2.4 요지)

- **SemS:** 이미지별 → 이미지 간 집계. NaN은 최악값(DSC=0, HD=이미지 대각선 등)으로 두거나
  rank-then-aggregate에서 최하위 순위. 다중클래스: 클래스 동등·불균형 보정이면 macro 평균, 아니면 가중.
- **ObD/InS:** 계층 데이터·이미지당 기대값이 중요하면 이미지별 집계(데이터셋 풀링보다 우선). NaN 사례는
  제외하되 **빈 정답+빈 예측이면 PPV(→Fβ)=1**. 정답 객체 없는 이미지는 Sensitivity 평균에서 제외,
  그 이미지의 FP는 PPV로 벌점. 크기변동(FP3.2)이면 크기별 층화.
- 계층 라벨: 클래스 간 상관 고려. 다중클래스: EC/MCC + 클래스별, FP2.5.1이면 가중.
- **비독립 사례(FP4.5): 계층구조를 존중해 집계**(GEE 류, Liang & Zeger 1986).
- **편향:** 장비·프로토콜·기관 메타데이터로 알고리즘 편향 탐색.
- **순위:** 관련 지표 동시 사용 금지, 순위 불확실성 명시.
- **보고:** 비결정성 → 여러 테스트 run; 원시 지표값 시각화; 결정 규칙이 있으면 혼동행렬 전체.
- **해석:** 주석자 내·간 변동 보고, 소수점 자릿수를 정답 불확실성에 맞춤(대개 소수 1자리 이상 무의미).
- 소표본 테스트셋 → 모든 지표에 신뢰구간.

## 6. 범위와 한계 (프레임워크 자체가 밝힌 것)

- 범위: n차원 영상에서 **범주형** 목표를 영상·객체·픽셀 수준으로 예측. 임상정보·이전 비디오 구간을
  맥락 입력으로 써도 됨. 다중라벨은 이진 문제로 분할. 질문별로 따로 권고.
- 범위 밖: 퍼지·다중관찰자 정답 생성, 회귀·재구성(향후 확장 예정), 강건성·신뢰성·공정성·환경비용
  (Green Algorithms, Carbontracker 참고), 임상 결과 검증(환자 결과 기반 임상시험은 별도 단계).
- **시간적(temporal)·추적 지표는 다루지 않음.** 비디오는 입력 맥락으로만 허용.
- 보정 권고는 ImLC 중심(SemS/ObD/InS 구체 권고 없음).
- 사용 사례 중 수술 관련: **대장내시경 비디오 수술기구 instance segmentation**(관형 객체 InS 사례로
  분류), 복강경 영상의 기구가 문제유형 비교 그림 예시로 등장.
