# 수술영상 과제 → Metrics Reloaded 매핑

표기: **[MR]** = Metrics Reloaded 본문 근거, **[적용]** = 이 스킬이 MR 원칙을 수술영상에 옮긴 판단
(연구마다 데이터로 확인할 것), **[외부]** = MR 범위 밖이라 다른 근거를 쓴 것(`sources.md`).

## 1. 과제별 문제유형과 권장 지표 묶음

| 수술영상 과제 | 문제유형 | 핵심 지표 묶음(출발점) | 주의 |
|---|---|---|---|
| 기구 존재(tool presence), 프레임/클립 단위 다중라벨 | ImLC (라벨별 이진) [MR: 다중라벨 분할] | 라벨별 AUROC + AP(희귀 기구), 결정 규칙 쓰면 Sens/PPV@목표값; 비디오 안에 양·음성이 충분하면 비디오별 계산 후 평균, 아니면 풀링 + cluster bootstrap | 기구별 유병률 차이 큼 → AP의 no-skill 기준선(=유병률) 함께 보고 [적용] |
| CVS(critical view of safety) 기준 충족 판정 | ImLC (3개 기준 각각 이진 + 전체 달성) | AUROC(주지표 후보), AP, 보정(S5); 경고·중단 같은 **실제 결정**에 쓸 때만 Net Benefit; 수술당 판정 1개면 풀링 계산 + cluster bootstrap(RF16) | **시점 정의**: 클립 적용 직전 기준점과 창 길이 사전 지정, 클립 어플라이어 노출 프레임 배제(누설, RF14) [적용]; 정답은 다중 평가자 합의가 필요한 퍼지 정답 → 합의 정답 생성 방법은 MR 범위 밖(RF13), 일치도 필수·자릿수 절제 [MR §6, P3.5] |
| 수술 phase/step 인식 (프레임별 다중클래스, 시간축) | ImLC(프레임 수준) **+ 범위 밖 시간적 측면** | 프레임 단위: 비디오별 Accuracy·phase별 Precision/Recall/Jaccard(또는 F1) → 비디오 간 평균±SD; 다중클래스 요약 BA 또는 MCC + 혼동행렬; **구간 지표**(segmental F1@k, edit score)로 과분할(flickering) 평가 [외부] | online/offline 명시; relaxed boundary 평가는 쓰지 않음(널리 쓰인 스크립트 버그로 값이 1을 넘을 수 있음)·비디오 vs 전체풀링 계산 방식을 반드시 명시(문헌 간 비교 불가의 주원인) [외부: Funke 2023] |
| 기구 검출(bbox) | ObD | Box IoU 기준(임계 명시) + Greedy-by-Score 할당 + **AP 또는 FROC**; 보조로 PPV@Sens=목표 | Accuracy/Specificity/AUROC 금지(TN 없음) [MR]; 가늘고 긴 기구 샤프트는 박스 근사 불량 → 점/마스크 기준 고려 [MR S8] |
| 기구 분할, 같은 종류 기구 동시 출현 가능(파지기 2개 등) | **InS** [MR: 다중 개체 → InS] | 검출: Mask/Boundary IoU 기준, AP 또는 PQ; 분할: 개체별 DSC + NSD | MR 사용례: 대장내시경 수술기구 InS(관형 객체) [MR]; 유형 선택은 S1(P1 함정), SemS로 두고 HD 쓰면 다른 개체 경계와 비교되는 오류(함정 논문 그림 분류는 P2.4) [MR] |
| 기구 분할, 클래스당 1개 보장 | SemS | DSC(또는 IoU 하나) + NSD(τ 명시) 또는 MASD; 샤프트 등 관형이면 clDice 고려 | 빈 프레임 다수 → NaN 규칙 사전 명시 [MR §5] |
| 해부구조 분할(담낭, 간, 담낭관·담낭동맥, 혈관, 신경) | SemS (구조당 1개) / 관형은 clDice | DSC + 경계 지표(NSD 또는 MASD); **담낭관·동맥·혈관은 clDice + 연결성** [MR FP3.3]; 작은 구조는 크기별 층화 | 분지(branch)·가림으로 한 구조가 여러 조각이면 FP3.6(비연결)로 두고 SemS 유지 — 서로 다른 개체(예: 동맥 2개)를 구분해야 할 때만 InS [적용]; 위치·존재 확인이 목적이고 경계가 덜 중요하면 ObD(점/중심 기준)도 후보 [MR S1]; 2D 영상은 mm 스케일 없음 → NSD τ·거리 단위 **픽셀**, 해상도 고정, τ 민감도 분석 [적용] |
| 안전/위험 박리 영역(Go/No-Go zone) | SemS(퍼지 정답) | DSC/Fβ(과·과소분할 비대칭 반영: No-Go 놓침이 더 위험하면 재현율 쪽 가중) + 경계 지표 | 정답이 본질적으로 모호 → 다중 주석자 정답 생성은 **MR 범위 밖** [MR §6]; 주석자 간 변동을 상한선으로 해석 |
| Action triplet(기구-동작-대상) | ImLC 다중라벨 | 성분별·triplet별 AP, 평균(mAP) — **공식과 평균 방식(비디오별/전체) 명시** | "mAP" 명칭 오용 사례 교훈 [MR P3] |
| 출혈·담즙유출·열손상 등 이벤트 탐지 | 프레임 ImLC 또는 시간적 이벤트 검출(범위 밖) | 프레임 단위: AUROC/AP + 결정 규칙 지표; 이벤트 단위: 이벤트 Sensitivity·이벤트당/시간당 오경보, 탐지 지연(latency) | 이벤트 단위 매칭 규칙(시간 허용창) 사전 정의 [적용] |
| 술기평가(GEARS, OSATS 등 점수) | **회귀/서열 — MR 범위 밖** | 연속 점수: MAE, 일치도(ICC, Bland–Altman), 순위상관; 서열 범주로 예측하면 **EC**(혼동 심각도 반영) [MR S2] | 정답 평가자 간 ICC를 성능의 상한으로 제시 [적용] |
| 비디오 → 술후 결과(합병증 등) 예측 | ImLC(비디오 수준) + 임상예측모형 | AUROC, 보정(slope·intercept·Brier), Net Benefit(결정곡선) | TRIPOD+AI 보고 [외부] |
| 기구·조직 추적(tracking), 키포인트, 깊이·3D 재구성 | **MR 범위 밖** | 과제별 표준 지표 + 그 근거 문헌을 별도 인용 | 설계서 한계에 명시 [MR §6] |
| 실시간 보조(모든 과제 공통) | 비참조 지표 | 추론 fps, 지연(ms), 하드웨어 명시 | MR 3번째 하위단계(비참조 지표) [MR] |

## 3. MR 범위 밖 과제 처리 원칙

1. 범위 밖임을 설계서 "한계"에 쓴다. MR을 근거로 쓰지 않는다(RF13).
2. **Phase 인식:** 프레임 단위 부분은 MR의 ImLC 원칙(다중클래스 요약 + 클래스별, 혼동행렬, 유병률
   주의)을 적용하고, 시간적 부분은 구간 지표를 추가한다. 계산 단위(비디오별 후 평균), relaxed 평가 금지,
   online/offline, 후처리(평활화) 여부를 명시 — Funke 등 2023이 지적한 문헌 간 불일치의 핵심 항목. [외부]
3. **회귀(술기 점수 등):** 오차(MAE/RMSE) + 일치도(ICC·Bland–Altman) + 정답 신뢰도. [외부·일반 원칙]
4. **퍼지 정답(Go/No-Go 등):** 다중 주석자 정답 융합 방법을 사전에 정하고 근거를 따로 인용.

## 4. 분석단위·분할 체크

- 표본수 단위 = 환자(수술). 프레임 수는 정밀도를 과장한다.
- 프레임 샘플링 fps를 명시(학습·평가 동일 여부).
- 같은 환자의 여러 비디오(분할 저장)는 같은 split에.
- 기관·플랫폼(예: SP vs Xi)·술자 경험 단계·난이도(염증, 유착) 메타데이터 수집 → 하위군 성능·외부검증.
- 학습곡선 연구 데이터와 겹치면 술자 경험이 교란요인이 될 수 있음을 기록. [적용]
