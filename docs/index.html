수술영상 CV 연구, 데이터 모으기 전에 설계부터

Claude 스킬 두 개로 수술 프로파일 → CV 과제 → 지표 → 주석·분할·보고 계획까지 담긴 설계서를 만듭니다. 이 페이지를 따라 하며 직접 설치하고, 각 단계에서 스킬이 무엇을 묻고 무엇을 결정하는지 미리 체험해 보세요.

근거: Metrics Reloaded (Nat Methods 2024) Claude Code · claude.ai GitHub
1수술 프로파일
2임상 질문 → CV 과제
3Fingerprint
4지표·적용 계획
5설계서 + 레드플래그
Step 1

설치

쓰는 환경을 고르고 명령을 복사해 실행하세요. 스킬은 두 개입니다: 범용 surgical-cv-study-design, 담낭절제 전용 cholecystectomy-vision-study-design.

터미널에서 두 줄이면 됩니다(권장).

claude plugin marketplace add jmleetpl/surgical-cv-skills
claude plugin install surgical-cv-skills@surgical-cv-skills
git clone https://github.com/jmleetpl/surgical-cv-skills.git
cp -R surgical-cv-skills/skills/* ~/.claude/skills/

PowerShell에서 실행합니다.

git clone https://github.com/jmleetpl/surgical-cv-skills.git
Copy-Item -Recurse -Force .\surgical-cv-skills\skills\* "$HOME\.claude\skills\"
  1. Releases에서 zip 두 개를 받습니다.
  2. claude.ai → 설정 → 기능 → Skills → 추가 → Skill 업로드.
  3. 두 파일을 한 번에 끌어다 놓고 업로드합니다.
확인: 새 세션에서 /surgical-cv-study-design을 입력했을 때 스킬이 자동완성되면 설치된 것입니다.
Step 2

첫 실행

수술명, 접근법, 규모, 임상 질문을 한 문단으로 주면 됩니다. 빠진 정보는 스킬이 한 번에 묻습니다.

/surgical-cv-study-design
간절제 영상 AI 연구를 설계해줘. 2개 기관, 로봇·복강경 180례, 1080p 30fps.
Q1 절리 중 간정맥·글리슨 분할(장래 실시간 경고), Q2 수술 후 phase 인식, Q3 출혈 이벤트 탐지.
스킬이 처음 확인하는 것: 수술명·접근법·플랫폼, 기관·술자 수, 비디오 수·해상도·fps, 사용 시점(online 실시간 vs offline 수술 후), 정답 형태, 그리고 기관 × 플랫폼 × 술식 교차표. 기관마다 플랫폼이 다르면 "기관 간 외부검증"이 사실상 플랫폼 비교가 되기 때문입니다.
입력 준비 체크
Step 3 · 스킬의 앞단

수술 프로파일

지표를 고르기 전에 수술을 먼저 정리합니다. 수술을 골라 스킬이 출발점으로 쓰는 프로파일 요약을 보세요. 임상 내용은 초안이며 연구팀이 확정합니다.

Step 4

임상 질문 → CV 과제 → 문제유형

Metrics Reloaded는 문제를 네 유형(이미지 분류 ImLC, semantic 분할 SemS, 개체 검출 ObD, instance 분할 InS)으로 나눕니다. 유형을 잘못 고르는 것이 첫 번째 함정입니다.

같은 종류 개체를 세거나 구분해야 하면(그래스퍼 2개, 림프절 여러 개) SemS가 아니라 InS/ObD입니다. 이어진 혈관 나무는 한 구조로 보고 SemS로 둡니다.
Step 5

Problem fingerprint

데이터와 과제의 성질을 체크하면 지표·설계가 어떻게 바뀌는지 바로 보입니다. 스킬은 이 항목을 질문별로 채우고 실제 데이터로 확인합니다.

설계에 반영할 것
    Step 6

    지표 적용·데이터 계획

    좋은 지표를 골라도 계산·집계를 잘못하면 틀립니다. 설계서에 반드시 들어가는 항목입니다.

    항목원칙
    분석단위환자(수술) 단위로 분할, 신뢰구간은 환자 단위 cluster bootstrap. 프레임을 독립 표본으로 쓰지 않음.
    집계분할·검출 지표는 프레임 → 비디오 → 전체. 수술당 판정이 하나뿐인 과제는 풀링해 계산하고 CI만 cluster bootstrap.
    빈 프레임2층 평가: 모든 프레임에서 존재 판정 + 구조가 있는 프레임에서만 분할 지표. 둘 다 비면 정답으로 셈.
    τ (NSD)2D 영상은 픽셀 단위. 이중주석 프레임의 주석자 간 경계거리에서 도출하고 민감도 분석.
    지연프레임 처리량(30 fps면 ≤33 ms)과 임상적 경고 지연(사건→경고 허용 시간)을 구분.
    보고모든 지표에 CI, 원시 분포 시각화, 혼동행렬, 여러 seed의 변동. 100%·0%는 정확 구간.
    정답 품질이중주석 비율과 일치도, 블라인드 재주석이 AI 초안 없이 시작했는지 명시.
    Phase 지표relaxed boundary 평가 금지, 비디오별 vs 풀링 명시, 구간 지표(segmental F1@k, edit score) 추가.
    Step 7

    레드플래그 자가점검

    설계서 마지막에 스킬이 돌리는 점검입니다. 내 연구 계획이 피한 항목에 체크하세요(브라우저에 저장됩니다).

      Step 8

      예시: 간절제 연구 설계 요약

      Step 2의 프롬프트로 시험 실행했을 때 나온 설계의 골자입니다(가상 시나리오).

      질문문제유형주지표프로파일이 바꾼 점
      Q1 간정맥·글리슨 분할SemS(구조별)구조가 있는 프레임의 clDice + 전 프레임 존재 판정 AP혈관은 실질이 열린 뒤에만 보임 → 주장을 "노출된 구조 인식"으로 한정, 노출 전 경고는 범위 밖
      Q2 phase 인식(offline)ImLC + 시간적비디오별 단계 F1 평균 + edit score·F1@k해부학적 vs wedge 절제로 단계가 조건부 → 단계가 있는 비디오에서만 계산
      Q3 출혈 이벤트이벤트 검출고정 오경보율에서 이벤트 Sensitivity절리 중 미세 삼출은 늘 있음 → 중증도 정의 필수, 흡인기·거즈가 정답 단서가 되는 누설 점검
